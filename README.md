# desafio-dio-engenharia-de-prompts
Projeto desenvolvido para o Desafio de Projeto da DIO, com foco em engenharia de prompts, testes e documentação de resultados.
Objetivo:
Criar um segundo cérebro baseado nos ensinamentos do Fischer Black e Myron Scholes, e suas metodologia para o cálculo de opções

Os testes realizados demonstraram que a forma como uma instrução é escrita influencia diretamente a resposta obtida.

Prompts com maior clareza, contexto, objetivo e estrutura tendem a produzir respostas mais direcionadas às necessidades do usuário.

Este projeto contribuiu para compreender melhor a importância da Engenharia de Prompts na utilização de ferramentas de Inteligência Artificial.
